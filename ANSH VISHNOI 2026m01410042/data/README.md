# 📊 Data Directory (`data/`)

## Overview
This directory stores both the untouched raw data and the sanitized, production-ready dataset generated by the cleaning pipeline.

## Subdirectories & Files
- **`raw/`**:
  - `retail_customer_sales_dataset.csv`: Untouched source dataset (7,084 records, 24 attributes) containing raw simulated transaction records across India (2023–2024), including missing values, casing variations, duplicates, and invalid date formats.
- **`processed/`**:
  - `cleaned_retail_sales_dataset.csv`: Sanitized dataset (7,002 unique records) where all categorical values are canonical, missing numerical values are imputed using segment medians, impossible values are corrected, chronological date contradictions are resolved, duplicates are eliminated, and engineered features (`Delivery_Days`, `Profit_Margin`, `Revenue_per_Customer`) are included.
