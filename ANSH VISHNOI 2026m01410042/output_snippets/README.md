# 📄 Output Snippets Directory (`output_snippets/`)

## Overview
This directory stores pre-computed terminal output execution logs and analytical text snapshots. These files provide immediate evidence of code execution, pipeline results, and statistical evaluations without needing to re-run the scripts.

## Directory Contents
- **`audit_summary_output.txt`**: Raw terminal output showing missing counts, percentages, duplicate count, and categorical casing frequencies.
- **`cleaning_log_output.txt`**: Execution log capturing deduplication, category standardization, and median imputations.
- **`outlier_detection_output.txt`**: Quantitative output of IQR fences, quartiles, and outlier proportions for Sales, Profit, and Income.
- **`groupby_results_output.txt`**: Tabular command-line outputs for the 5 business groupby questions.
- **`test_execution_output.txt`**: Full test execution report from the `pytest` automated test suite.
